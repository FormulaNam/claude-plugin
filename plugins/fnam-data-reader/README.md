# FNam Data Reader (Claude edition)

FNam Data Reader helps Claude read and interpret measurement data and metadata
generated by FormulaNam (FNam) apps. It analyzes signals and numerical values and
connects measurement settings, labels and event records, while keeping file
relationships, stored values and computed values explicitly separated.

Version 1.0.0 (initial release).

## Supported apps and formats

FNam FFT Spectrogram Analyzer:

- 16-bit PCM mono/stereo WAV
- Supported single-column PCM CSV
- Measurement Info and Analyzer labels
- Sound Event Logger records and related audio clips
- Frequency Response Preview sessions, reference/recorded signal CSVs and stored
  FIR models, including magnitude, phase and impulse-response plots

App-specific formats from other FNam apps are not currently supported.

## Contents

- `skills/fnam-core`: file inventory, format identification, file-reference
  resolution, bounded ZIP handling and provenance rules
- `skills/fnam-analyzer`: Analyzer data analysis (RMS, FFT, spectrograms, labels,
  event records, Frequency Response Preview and FIR response)

## Install

In Claude Code:

```
/plugin install fnam-data-reader --marketplace FormulaNam/claude-plugin
```

On claude.ai or in the Claude desktop app (paid plans): open Customize > Plugins,
choose Add > Add marketplace, and enter `FormulaNam/claude-plugin`.

## Usage

Attach a WAV file, an exported folder or a ZIP and ask, for example:

- "Analyze the attached WAV or measurement data."
- "Find the measurement settings and labels linked to the attached data."
- "Analyze the Frequency Response Preview session and show the stored FIR response."

For the most complete analysis, include related metadata and keep the original
folder structure when sharing a ZIP. Missing settings and unconfirmed file
relationships are reported as such rather than guessed.

## Requirements

Numerical analysis requires a code execution environment with Python 3.10 or
later and NumPy. Plot rendering additionally requires Matplotlib. Available
features depend on the host environment and its file access.

## What it runs, sends and fetches

- Runs: the bundled Python scripts, on files you provide, in the host's code
  execution environment.
- Sends: nothing. The scripts make no network requests and do not upload
  measurement files to FormulaNam servers. Files you give an AI service are
  processed and retained under that service's policies and your settings.
- Fetches: nothing from the internet.

Source measurement files are not modified. Plots are written only to a separate
output location.

## Limitations

- Digital dBFS alone does not establish calibrated sound pressure level (dB SPL).
- FIR response magnitude in dB is a model output/input ratio relative to 1, not
  dBFS or dB SPL.
- Results do not certify measurement accuracy or file authenticity.
