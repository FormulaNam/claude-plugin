# FormulaNam Claude Plugins

Claude plugins published by FormulaNam for working with data from FNam apps.

## Plugins

| Plugin | Description |
|---|---|
| [FNam Data Reader](plugins/fnam-data-reader) | Read and analyze measurement data and metadata generated by FNam apps |

## Install

In Claude Code:

```
/plugin install fnam-data-reader --marketplace FormulaNam/claude-plugin
```

On claude.ai or in the Claude desktop app (paid plans): open Customize > Plugins,
choose Add > Add marketplace, and enter `FormulaNam/claude-plugin`.
